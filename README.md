# DSA Revision — Personal Cheat Sheet

A fast, visual DSA revision frontend designed for quick memory refresh sessions before coding interviews.

## ✨ Key Features
- **Java Collections Framework Reference**: The 4 original hierarchy diagrams with interactive zoom, pan, and fullscreen support.
- **Java Inbuilt Functions**: Method syntax, return values, meanings, and DSA memory hints across 18 Java topics.
- **DSA Problem-Solving Notes**: Topic-specific patterns, formulas, and think cues (Numbers, Arrays, Strings, Two Pointer, Sliding Window, DP, etc.).
- **Time & Space Complexity Reference**: Detailed complexity tables for Sorting, Searching, and Data Structure operations, plus Big-O quick memory cards.
- **Responsive Frontend**: Mobile-first design with smooth drawer navigation, self-contained scrolling, and fixed black + silver theme.

## 🛠️ Tech Stack
- **Framework**: React 18
- **Bundler**: Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Mobile-first responsive design)

## 🚀 Getting Started

### Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deployment (Vercel)
This project is configured for seamless deployment on Vercel:
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`
